# สมุดสรุป

เว็บรวมชีทสรุป PDF ฟิสิกส์กับคณิตศาสตร์ ฝากฟรีบน GitHub Pages

## ขึ้นเว็บครั้งแรก (ประมาณ 10 นาที)

1. สมัครบัญชีที่ github.com (ฟรี)
2. กด **+** มุมขวาบน แล้วเลือก **New repository** ตั้งชื่อ เช่น `sumdsarup` เลือก **Public** แล้วกด **Create repository**
3. ในหน้า repo กด **uploading an existing file** แล้วลากไฟล์ทั้งหมดในโฟลเดอร์นี้ไปวาง (`index.html`, `site.json`, `.nojekyll` และโฟลเดอร์ `pdfs`) แล้วกด **Commit changes**
4. ไปที่ **Settings → Pages** ตรง Branch เลือก `main` และ `/ (root)` แล้วกด **Save**
5. รอ 1–2 นาที ลิงก์เว็บจะขึ้นด้านบนของหน้านั้น หน้าตาประมาณ `https://ชื่อผู้ใช้.github.io/sumdsarup/`

## เพิ่มชีทใหม่

1. ใน repo เข้าไปที่โฟลเดอร์ `pdfs/physics` หรือ `pdfs/math`
2. กด **Add file → Upload files** แล้วลากไฟล์ PDF ไปวาง จากนั้นกด **Commit changes**
3. ชีทจะขึ้นบนเว็บเองภายในไม่กี่นาที (ถ้ายังไม่ขึ้น ให้รีเฟรชหน้าเว็บ)

ชื่อไฟล์จะกลายเป็นชื่อเรื่องบนการ์ด ถ้าใส่ตัวเลขนำหน้า เช่น `01 การเคลื่อนที่แนวตรง.pdf` ชีทจะเรียงตามเลข และเลขจะไม่แสดงในชื่อเรื่อง

ถ้าจะลบชีท ให้เปิดไฟล์ PDF นั้นใน repo แล้วกดไอคอนถังขยะ

## แก้ชื่อเว็บ ข้อความโน้ต หรือรายละเอียดของชีท

เปิดไฟล์ `site.json` ใน repo แล้วกดรูปดินสอเพื่อแก้ไข

```json
{
  "title": "สมุดสรุป",
  "message": "ข้อความที่จะโชว์ในกล่อง note",
  "repo": "",
  "notes": {
    "01 การเคลื่อนที่แนวตรง.pdf": {
      "topic": "ม.4 เทอม 1 · บทที่ 2",
      "note": "สูตรหน้า 3 ออกสอบบ่อย"
    }
  }
}
```

- `notes` ใส่บทหรือข้อความสั้น ๆ ให้ชีทแต่ละไฟล์ได้ โดยใช้ชื่อไฟล์ให้ตรงกันทุกตัวอักษร
- ถ้าไม่อยากโชว์กล่อง note ให้ใส่ `"message": ""`
- ปกติ `repo` เว้นว่างไว้ได้ เว็บจะหาเองจากลิงก์ แต่ถ้าใช้โดเมนของตัวเอง ให้ใส่เป็น `"ชื่อผู้ใช้/ชื่อrepo"`

## หมายเหตุ

- repo แบบ Public หมายความว่าใครมีลิงก์ก็เปิดอ่านได้
- ไฟล์แต่ละไฟล์ต้องไม่เกิน 25 MB ถ้าอัปโหลดผ่านหน้าเว็บ GitHub
- เครื่องหมาย "อ่านแล้ว" จะจำไว้ในเบราว์เซอร์ของเครื่องที่กดเท่านั้น
